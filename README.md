# YttriumLab Periodic Table

A simple static web page built with HTML, CSS, JavaScript, and jQuery.  
It displays periodic table data from `PeriodicTable.json`.

## Features

- Static web page
- Built with HTML, CSS, JavaScript, and jQuery
- Uses `PeriodicTable.json` as the data source

## Usage

Clone or download this repository, then open `index.htm` in your web browser.
